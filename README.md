# QuackWell

[English](README.md) | [Español](README.es.md)

Game created in 48 hours for **Ludum Dare 48**, whose theme was *Deeper and deeper*.

## About

QuackWell is an endless platformer where, in order to save the QuackWorld all the ducks live in, you'll have to endlessly try to defuse as many bombs as possible during your own personal odyssey through the depths of Destiny's Well.

## Controls

| Action | Keyboard | Controller |
| --- | --- | --- |
| Move | `W` `A` `S` `D` | Right thumbstick |
| Dash | `Space` | Right face button (Xbox: B / PlayStation: O) |
| Confirm | `Space` | Bottom face button (Xbox: A / PlayStation: X) |

## Development

The project was developed with **Unreal Engine 4.26** and combines C++ with Blueprints.

To open it, install Unreal Engine 4.26.x and open `ld48.uproject`. The configured startup map is `Content/Levels/TestLevel_P_Main`.
