# QuackWell

[English](README.md) | [Español](README.es.md)

Juego creado en 48 horas para **Ludum Dare 48**, cuyo tema fue *Deeper and deeper*.

## Sobre el juego

QuackWell es un juego de plataformas sin fin en el que, para salvar el QuackWorld en el que viven todos los patos, tendras que intentar desarmar sin cesar el mayor numero de bombas posible durante tu odisea personal por las profundidades del Pozo del Destino.

## Controles

| Accion | Teclado | Mando |
| --- | --- | --- |
| Movimiento | `W` `A` `S` `D` | Stick derecho |
| Dash | `Espacio` | Boton frontal derecho (Xbox: B / PlayStation: O) |
| Confirmar | `Espacio` | Boton frontal inferior (Xbox: A / PlayStation: X) |

## Desarrollo

El proyecto se desarrollo con **Unreal Engine 4.26** y combina C++ con Blueprints.

Para abrirlo, instala Unreal Engine 4.26.x y abre `ld48.uproject`. El mapa de inicio configurado es `Content/Levels/TestLevel_P_Main`.
